04 / THE MINI GLOSSARY

Tech words, decoded.

The language of technology shouldn't feel like a secret code.

HTML
HyperText Markup Language. It gives a web page its structure and meaning.
CSS
Cascading Style Sheets. They control how a web page looks, feels and adapts to different screens.
API
Application Programming Interface. It defines how different software systems communicate.
Open source
Software whose source code is made available under a licence that allows specified uses, access and modification.
