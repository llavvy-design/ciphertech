04 / THE TECH DICTIONARY

Don't know a word?
Start here.

A few useful terms you'll encounter along the way.

Frontend
The part of a website or application people directly see and interact with.
Backend
The server-side part of an application that handles tasks such as processing requests and accessing data.
Algorithm
A defined sequence of steps used to solve a problem or complete a task.
Machine learning
A branch of artificial intelligence in which computer systems learn patterns from data to make predictions or decisions.
Cloud computing
The delivery of computing resources, such as servers and storage, over a network.
UI / UX
User interface focuses on the controls and visual elements people use. User experience focuses on the overall experience of using a product.
